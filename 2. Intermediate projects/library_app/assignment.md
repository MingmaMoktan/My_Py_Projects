# Assignment instructions

Keep the functionality of the application like it is currently.

`readme.MD` contains instructions on how to prepare and use the project.

## Steps

1. Refactor the code
    1. Split the main.py into multiple files in a sensible manner
    2. Rename variables and functions to be more readable
    3. If you think there is a better way to handle some functionalities, feel free to refactor the code to be better
    4. Use at least one software design pattern of your choosing
        - Could be for example factory pattern for creating new books, singleton for settings, or something else
2. Write docstrings for modules, classes, and functions
3. Write unit test for the application
4. Run the tests and create documentations
